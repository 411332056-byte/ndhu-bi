# 台灣發電機構圖鑑

以台電開放資料分析台灣 2006–2025 年的發電結構變化，並介紹各種發電機構的運作原理。

網站：開啟 GitHub Pages 後的網址（Settings → Pages → `main` / root）

## 資料來源

| 項目 | 內容 |
|---|---|
| 發布機關 | 台灣電力股份有限公司 |
| 資料集 | 台灣電力公司發購電量(能源別)及公用售電業售電量(用途別) |
| 平臺 | 政府資料開放平臺 <https://data.gov.tw/dataset/35392> |
| 原始檔 | `d003005/001.csv`（發購電量，能源別）、`d003005/002.csv`（售電量，用途別） |
| 資料期間 | 2006–2025 年，年資料 |
| 原始單位 | 度（kWh）；網站換算為億度（1 億度 = 1 億 kWh） |
| 授權 | 政府資料開放授權條款－第 1 版 |
| 下載日期 | 2026-10-12 |

原始檔放在 `raw/`，內容與台電伺服器提供的檔案逐位元組相同，SHA-256 記錄在 `data/etl_report.json`：

- `raw/taipower_d003005_001_generation_by_source.csv`：Big5 編碼，422 列
- `raw/taipower_d003005_002_sales_by_use.csv`：UTF-8（含 BOM），80 列

## 資料夾結構

```
raw/        原始資料（未修改）
etl/etl.py  ETL 程式（只用 Python 標準函式庫）
data/       ETL 輸出，網站直接讀取這些檔案
index.html  網站（Chart.js 4.4.1）
```

## 執行 ETL

```bash
python etl/etl.py
```

輸出：

| 檔案 | 內容 |
|---|---|
| `data/generation_long.csv` | 逐列清理後的原始資料，加上分析類別、是否再生能源、億度、資料旗標 |
| `data/generation_by_group.csv` | 每年 × 11 個能源類別的發購電量（億度）與占比（%） |
| `data/annual_summary.csv` | 每年總量、再生能源量與占比、再生能源年增率、燃煤/燃氣/核能/火力占比、售電量 |
| `data/sales_by_use.csv` | 每年住宅、工業、商業、其他售電量 |
| `data/category_map.csv` | 原始 16 種能源別 → 11 個分析類別的對照表 |
| `data/etl_report.json` | 原始檔雜湊值、所有核對結果與警告 |

## 資料核對

ETL 會做以下核對，任何一項失敗就停止且不寫出資料：

1. 欄位名稱符合預期
2. 年度連續、沒有重複列（年度 × 發購電 × 能源別）、沒有負值、沒有未知能源別
3. **各類別加總 = 該年總發購電量**（20 個年度皆核對，差異 < 1 度）
4. 每年各類別占比合計 = 100%
5. 售電量年度與發購電量一致，且售電量小於發購電量
6. 與台電公布的 2025 年數字比對：總量 2,524.4 億度、再生能源 12.7%、核能 1.2%

目前結果：30/30 通過。

## 分類口徑與限制

- 統計範圍為台電系統（台電自發＋購電），不含轉供、直供與自用發電設備。
- 再生能源＝太陽光電、風力、水力（慣常、承攬、購電小水力）、地熱、生質能、廢棄物、垃圾沼氣。依此口徑，2025 年為 12.66%，與台電公布的 12.7% 一致。
- 抽蓄水力與儲能電池屬於儲能，不計入再生能源。
- 汽電共生單獨列為一類，在網站的「只看火力」篩選中與燃煤、燃氣、燃油合併，所以火力占比會比台電新聞稿略高。
- 原始檔中 2025 年台電燃氣為科學記號 `1.01022E+11`，只有 6 位有效數字，誤差約 ±0.05 億度。ETL 照原值使用並在 `etl_report.json` 標記。
- 空白欄位視為 0（該年尚無此類發電）。

## 網站功能

- 圖 1：各能源別發購電量堆疊長條圖，可選年份區間、切換億度／占比、篩選能源類別
- 圖 2：再生能源占比（折線）與年增率（長條）組合圖，以及所選區間各再生能源類別的增量與年均成長率排名
- 表 1：任一年度的各類別發購電量、占比與年增減
- 自動計算的觀察重點（燃氣超越燃煤的年份、核能占比變化、太陽光電成長倍數等）
- 七種發電機構的原理說明，並附上資料集中的實際發電量

直接雙擊開啟 `index.html` 時，瀏覽器會擋住讀取本機 CSV。請用 GitHub Pages，或在本資料夾執行 `python -m http.server` 後開啟 <http://localhost:8000>。
